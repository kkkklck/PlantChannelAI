# Frozen methods in the public reproduction

The authoritative logic is the supplied executable code, not this short description. All eight methods consume the same finalized evidence vector and do not read reference labels.

| Method | Definition |
| --- | --- |
| C0 | Constant abstention comparator |
| C1 | Constant direct-claim withholding comparator |
| C2 | Ionic-component criteria: qualifying current/flux and physical ion identity; otherwise withhold when an observation exists, or abstain when none exists |
| C4 | Full frozen molecular-attribution engine followed by the unchanged B5 terminal mapping |
| A1 | Remove the molecular-attribution requirement while preserving provenance and host/catalytic alternative controls |
| A2 | Remove host/catalytic separation requirements while preserving molecular-attribution and provenance requirements |
| A3 | Replace C4 abstention with withholding |
| A4 | Diagnostic provenance relaxation: unresolved/conflicting source-mapping fields are set to exact for the engine rerun; other input fields stay unchanged |

Exact edge cases, directly established host/non-ionic assignments, validation failures and ablation fallback states are defined in `Code/92_confirmatory_validation_v2/method/v2_method.py` and `Code/77_v3_2_54_current_ownership_audit/current_ownership_audit.py`.

Physical-ion identification uses predeclared carrier tests, including controlled-gradient reversal, bi-ionic permeability, direct tracer or encapsulated-system flux, and single-channel ion identity. Attribution uses specified loss-and-rescue/pathway-mutation support or qualified purified-protein reconstitution. Host and catalytic separation use the engine's applicability rules. The method module contains the pre-existing integrity checks for the frozen engine and mapping.

The directory names refer to their development stages; they do not imply that V3 was an unchanged execution of V2.1. The archived profile and original protocols are historical records. S18 is the case-level source for actual initial extractor history.
