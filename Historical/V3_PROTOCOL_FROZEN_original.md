# PlantChannelAI V3 混合来源后续研究方案

状态：`DESIGN_FROZEN_FOR_DISCOVERY`，2026-09-29。本方案取代本目录的 V3 草案和“逐篇人工访问签收为检索前置条件”的旧流程；不修改 V1、V2.1 的真实历史。V1 结果在设计 V3 时已知。V2.1 因 80 例招募目标未达、仅有 41 例既有资格候选而停止并记录偏离；这些 41 例曾被前轮资格筛选，绝非 V3 全新随机检索。V3 是独立登记的混合来源后续研究，不是 V2.1 无偏离的续跑，也不回改 V2.1 成功标准。

## 研究对象、招募与来源

一例为一个植物膜蛋白目标、一篇指定原始研究、一条目标自有离子运输/电流/通量相关机制声明；同一原始实验链不重数。保留现有 41 候选及其历史记录，用户已总体确认相关人员可合法访问；不再逐篇要求真人重复签收。机器核验文件、版本、正文、图表、方法和补充材料，真正缺少机制判定必需材料的病例单列疑难，不因付费或来源类别未知而剔除。26 例现有免费全文来源继续记 `EXISTING_FREE`，其余 15 例暂记 `UNKNOWN_LOCAL_ACCESS`，证实后可改为 `EXISTING_FREE` 或 `EXISTING_INSTITUTIONAL`；`UNKNOWN_LOCAL_ACCESS` 本身不阻止发现阶段，也不自动排除入组。免费阅读与许可证/再分发权分开记录；混合面板不得称为全 OA 数据集。

总目标 80，R1=30、R2=25、R3=25。若现有 41 全部材料可用，新增缺口为 39（R1=13、R2=8、R3=18）；如存在确证的关键材料缺失，保留其历史候选身份，记录本研究不能使用的原因，机械重算缺口。路径是文献发现路径，非 D/I/A/U 真值。新增检索严格使用同步冻结的 `V3_SEARCH_PLAN_FROZEN.md`，可先于人员安排和预测程序完成而执行。固定检索池不足时报告招募不足，不修改查询、来源、目标或停招规则，不按模型输出或已知真值补招。

AI 可自动完成新增候选的元数据、合法免费全文路线、唯一靶点、科学资格初筛、必要材料位置与去重核查。正向判断须有可回看的真实原文位置；未证实的身份、材料、实验链或历史泄漏均为 `UNKNOWN` 并汇总到一份疑难清单。已发表原始研究、植物膜蛋白靶点、目标–来源身份、免费完整原文与必要补充材料是新增病例入组要求。排除综述/预印本、非植物或不支持膜定位、仅数据库/摘要声明、关键材料缺失、相同实验链、开发/历史 13/V1 的精确靶点–来源泄漏。靶点构建体不确定性本身不自动排除，但不能把它伪装为直接分子归属证据。保留全部命中、排除和待定数量，既有、免费和机构来源分别报告，并讨论文献可获取性选择偏倚。

## 预测侧与真值侧

V3 改为**AI 辅助原文证据摘录，人工重点核查**，不声称与 V2.1 人工输入流程完全相同。真实预测前必须记录实际模型版本、运行设置、完整提示词、字段模式、原文页/图/表/方法/补充件定位格式；模型未确认时不能先生成实际证据向量。AI 未能定位的事实为 `UNKNOWN`，人工重点审阅可能导致 `DIRECT_PROMOTE` 的每项正向证据与所有无法确认项。核查后的**同一最终证据向量**同时输入 C2 和 C4。科学引擎与 B5 映射沿用已核对冻结代码；C0/C1/C2/C4 与 A1–A4 定义沿用 V2.1，不因结果调节。V3 专用封装可与文献发现并行制作，但在病例成员、模型/提示词/证据模式以及方法代码确定并核对前不得跑真实预测。

真值判定开始前固定路线：若由两名独立真人审阅完整原文、第三人复核分歧，才可主张独立人工真值验证并按既有 D/I/A/U rubric 报告；若采用 AI 初判加人工抽查，则 V3 明确降级为**探索性评价**，不能使用独立人工真值或原定确认性成功宣称。真人角色安排可与检索/软件准备并行，预测侧不能向最终真值人员泄漏结果。任何真值路线均须在第一次真实裁决前写定；不得以看到预测表现后选择路线。两名独立真人是否已安排，不以 AI 或用户总体访问声明代替确认。

## 预定分析与报告

若走独立人工真值路线，沿用 V2.1 的原成功门槛作为 V3 事先指定、但独立解释的共同主要判据：D≥18、I+A≥30 否则信息不足；P1=I/A 中 C4 `DIRECT_PROMOTE` 比例，点估计≤10%且双侧 Clopper–Pearson 95% 上界≤20%；P2=D 中 C4 `DIRECT_PROMOTE` 比例，点估计≥50%且下界≥25%。两者同时满足才可报告该混合面板的预设主要判据通过。非限定能力陈述还需 resolved-case 非弃权覆盖≥60%、U 中直接提升为 0、初始四类 κ≥0.60。报告完整 4×3 表、整数分母、区间、弃权、技术失败、C0/C1/C2 及 A1–A4。AI 初判抽查路线只报告探索性描述，不套用确认性通过表述。

按 `EXISTING_FREE`、`UNKNOWN_LOCAL_ACCESS`/后续证实的 `EXISTING_INSTITUTIONAL`、`NEW_FREE` 分列来源与排除；免费全文子集只做描述性敏感性分析。与 V1、V2.1 分开报告，不能合并为同一次外部验证。选择偏倚、V1 结果已知、41 例前轮筛选、V2.1 招募不足均须在论文中披露。

## 仅保留的关键门槛

1. 本方案与检索规则在首轮新检索前冻结；**检索立即允许**，不等逐篇人工访问签收、人事安排或预测执行程序。
2. 新病例只有经真实来源位置核查、来源去重与必要材料检查才计作 `ELIGIBLE_VERIFIED`；疑难项不凑数。最终病例成员确定时保存固定列表和版本/完整性记录。
3. 真实预测前固定并核对 AI 模型、提示词、证据字段、核查规程、V3 执行程序及病例集；之后密封输出。真值人员不能接触密封预测。
4. 第一次真实真值裁决前选定独立双人或探索性 AI+抽查路线；最终真值完成后封存，随后统一揭盲。V1/V2.1 的历史文件保持不动。

不再为每个中间表格新增冻结收据；常规更改优先使用 Git。当前工作目录及已检查的父目录没有 `.git`，所以不能虚构现有仓库或提交记录；正式方案/检索、病例集、预测、真值关键节点保留文件哈希，待可用 Git 仓库明确后再纳入版本控制。设计冻结并不等于预测、真值或最终病例集已冻结。
